## 1. What is Halting problem and how does Turing proves about it?
Halting Problem: Determine if a program will eventually stop (halt) or run forever.<br>
Turing's Proof: Impossible. He proved by contradiction:<br>
i. Assume a machine H exists that can check if any program halts<br>
ii. Create a new program that does the opposite of H (if H says halt, loop forever; if loop, halt)<br>
iii. This creates a paradox → H cannot exist<br>
Conclusion: No algorithm can solve the halting problem. Some problems are undecidable.<br>
